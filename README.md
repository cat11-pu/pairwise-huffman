# huffman

一个只依赖 Python 标准库的霍夫曼熵编码内核。它不监听端口、不读写文件，
只在内存里按符号权重建码表、把字节编成带补位的位流、再把位流解回字节。

- 建表：权重 → 二叉建树 → 各符号码长 → 规范码值（码长相同按符号值分配）
- 编码：码位高位在前打包，最后一个字节的剩余位按 PAD_BIT 补齐，码位总数单独记录
- 解码：按码表建前缀树逐位下行，走到记录的总位数为止
- 错误情形：码长超过上限、符号在表里没有码、记录位数与载荷对不上

## 目录

- huffman/core.py：建表、编码与解码
- tests/test_core.py：行为测试

## 跑测试

在项目根目录执行：

    python3 -m unittest discover -s tests -v
